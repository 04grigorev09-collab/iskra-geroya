# Искра Героя (PWA)

Оригинальная мобильная экшен-RPG в жанре «бей монстров → неси добычу на базу → прокачивайся» (жанр idle-arcade action RPG).
Весь код, графика (canvas) и звук (WebAudio) сгенерированы с нуля, сторонних ассетов нет.

## Файлы
- `index.html` — вся игра (JS/CSS внутри, внешних зависимостей нет)
- `manifest.webmanifest`, `sw.js` — PWA и офлайн-кэш
- `icon-180.png`, `icon-192.png`, `icon-512.png`, `favicon.ico` — иконки
- `screenshot_*.png` — скриншоты из headless-теста (iPhone 390×844)
- `test.js`, `test2.js`, `sim.js` — headless-тесты и симуляция баланса (нужен `npm i playwright-core` и Chrome)

## Как поставить на iPhone
Service Worker (офлайн) работает только по HTTPS (или на localhost). Варианты:
1. Положить папку на любой свой HTTPS-хостинг → открыть в Safari → «Поделиться» → «На экран „Домой“».
2. Для проверки в локальной сети: `python3 -m http.server 8000` на компьютере и открыть `http://<IP-компьютера>:8000` в Safari на iPhone
   (игра работает, «На экран Домой» тоже, но без HTTPS офлайн-кэш не включится).

Сохранение — в localStorage (автосохранение каждые 5 с), есть экспорт/импорт кода сохранения в настройках.

## Управление
Палец по экрану — бег (атака автоматическая). Кнопки: Рывок, Домой, Назад, Прокачка, АВТО.
ПК: WASD/стрелки, Пробел — рывок, H — домой, B — назад, U — прокачка, T — авто, Esc — пауза.
